# ADR 0056：本地确定性质量门禁

仓库提供两个不依赖外部服务的质量门禁：`pnpm lint` 扫描 `src` 和 `apps` 中的 JavaScript/TypeScript 文件，拒绝 `debugger`、`eval` 和 TypeScript 抑制指令；`pnpm scan:secrets` 对同一范围执行有界秘密和危险文件扫描，检查危险文件名、私钥、常见 token/密钥格式和凭据式赋值。

扫描器支持显式路径，限制单文件 1 MiB、最多 5000 个文件，忽略二进制内容和依赖/构建目录；发现问题、缺失路径或超限均以非零退出。该门禁只提供本地确定性信号，不替代真实外部服务验收。
