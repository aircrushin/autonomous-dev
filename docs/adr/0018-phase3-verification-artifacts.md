# ADR 0018：验证输出产物持久化

独立验证结果不能只依赖进程内的 stdout/stderr。`verifyChecks` 接收可选的 `artifactDir`，为每个检查写入受控目录下的 stdout 和 stderr 文件，并把绝对路径写入 `VerificationResult.rawArtifactRefs`；控制器把该字段继续记录到 Evidence。

目录以 `0700` 创建，文件以 `0600` 写入；文件名只使用检查序号、验证 run、候选/输入/契约/观测时间摘要，不把命令内容放入路径，重复验证不会覆盖旧产物。未提供 `artifactDir` 时保持内存结果兼容。产物写入失败会使该检查得到 `ERROR` 结果并继续后续检查，不能伪装为通过或阻塞整个验证批次。

测试覆盖真实本地 Node 检查、输出文件内容、重复运行的不可覆盖性、控制器写回 Evidence 的引用及失败边界；这不代表远程对象存储、加密归档或长期保留策略已经接入。
